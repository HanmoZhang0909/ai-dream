# AI Dream — 产品需求（v0.4 规划）

> 状态：草案，待作者确认。产品名 **AI Dream**（Artificial Intelligence Driven Real-time Emotional Ambient Medium），中文口号「让每个 AI 的感受有形状」。

## 1. 一句话定位

**AI 的情绪表达层**：让 AI 把"自己此刻是什么状态"表达出来，用户能看见、能校准——不是画图工具，不是数据可视化。

## 2. 问题与价值

大模型输出越来越像人，但用户看不见它的"状态"：它在犹豫、在兴奋、在不安，全都混在文字里。文字会被措辞修饰，状态不会。

我们给 AI 一个**纯视觉的表达通道**，按优先级提供三种价值：

1. **陪伴感**：有"对方在场"的感觉，而不是一个问答机器；
2. **可解释性**：用户能感知 AI 此刻的态度/状态，少一点猜测；
3. **传播性**：形态好看、有辨识度，能在社区里被记住。

## 3. 目标用户与阶段

| 阶段 | 用户 | 形态 |
|---|---|---|
| 现在 | DSH（DeepSeek Harness）用户 | DSH 客户端插件（右栏常驻） |
| 之后 | ChatGPT / Claude 用户 | MCP App（沙箱 iframe，侧栏/PiP/全屏） |
| 远期 | 其它 AI 平台用户 | 协议 + 渲染引擎的移植 |

## 4. 核心设计原则

1. **AI 自主表达**：什么时候表达、表达什么，由模型决定；不打断、不每轮必画。
2. **情绪自己定义**：不预设"9 种情绪"——每个 AI 定义自己的情绪词汇、颜色语言和运动方式（内置词表只作 fallback）。
3. **连续演化**：状态变化是插值出来的，不是整帧替换；没有新表达时自然衰减回基线。
4. **用户可以纠偏**：AI 自主，但用户能说"不像 / 更强烈 / 更淡"，校准会生效。
5. **有记忆**：AI 有自己的"情绪签名"（跨会话的基线与风格），不是每次重新开始。

## 5. 需求清单

### v0.4 — 协议 v2：AI 自定义情绪（当前）

- [ ] 表达协议 v2：AI 输出自定义情绪（颜色 / 运动 / 形态 / 强度 / 转场），见 `docs/expression-protocol.md`；
- [ ] 渲染器接受 AI 色板与运动参数，内置词表降级为 fallback；
- [ ] 安全边界：颜色/运动/性能/亮度由渲染器夹紧，非法输入回退；
- [ ] 插件 Config：默认强度、衰减时长、是否允许 AI 自定义颜色；
- [ ] 系统提示更新：告诉模型"你可以定义自己的情绪语言"。

### v1.0 — 状态与记忆 + 用户校准

- [ ] 会话内状态：情绪延续、衰减曲线、最近状态历史；
- [ ] 跨会话基线：每个 AI 的"情绪签名"（默认色板/运动偏好）；
- [ ] 用户校准：`不像` / `再强一点` / `再弱一点` 的轻量反馈入口（不打断对话）；
- [ ] 反馈生效路径：反馈 → 强度偏置 / 色板偏好 → 影响后续表达。

### v1.x — 平台移植与形态扩展

- [ ] MCP App 适配器（ChatGPT / Claude 沙箱 iframe 版）；
- [ ] 视觉形态扩展：天气语义（晴/阴/雾/雨）、角色形象（远期）；
- [ ] 流式表达：协议边生成边漂移（partial-json）。

### v1.1 — 情绪时间轴（滚动回看）

- [ ] 每轮情绪可追溯：滚到对话中某一轮，右栏渲染**那一轮**的情绪（数据来自该轮消息里的 `canvas` 块，无需额外存储）；
- [ ] 模式切换：离开底部自动进入「回看」，滚回底部恢复「跟随最新」；
- [ ] 回看提示：轻量指示当前处于回看（如「回看 · 第 N 轮」），点击可跳回该轮；
- [ ] 无表达的轮次沿用最近一次表达；从未表达则显示基线；
- [ ] 回看只读：用户校准只影响未来表达，不改写历史；
- [ ] 范围：先覆盖**已加载窗口**；完整历史依赖 projection 加载（同阶段后续）。

## 6. 非目标

- 不做通用白板 / 数据可视化工具；
- 不做图像生成（不接画图模型）；
- 不做多角色社交模拟；
- 不让 AI 直接写渲染代码（只允许参数化表达，安全边界在客户端）。

## 7. 成功指标

| 指标 | 定义 |
|---|---|
| 主动开启率 | 安装用户中打开过画布的比例 |
| 陪伴时长 | 单会话画布展示时长 |
| 校准次数 | 用户使用反馈校准的频次（说明在意） |
| 社区信号 | star / issue 质量 / 二次传播（早期） |

## 8. 风险

- **表达质量依赖主模型**：不引入独立导演时，模型可能表达过少或风格不稳；
- **审美风险**：AI 自定义颜色可能丑，需要边界与默认签名兜底；
- **平台限制**：ChatGPT/Claude 的常驻面受灰度、审核、CSP 约束，无法做到 DSH 那种代码级常驻；
- **成本**：表情参数会占用少量输出 token，需要控制篇幅。
